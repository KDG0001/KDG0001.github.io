# 공유 자료 폴더

이 폴더에 파일을 올리고 main 브랜치에 저장하면 사이트 자료실에 자동으로 표시됩니다.

- 자료실: https://kdg0001.github.io/downloads/
- 업로드: https://github.com/KDG0001/KDG0001.github.io/upload/main/downloads/shared
- 다운로드에는 로그인이나 별도 가입이 필요하지 않습니다.
- 업로드와 수정은 저장소 쓰기 권한이 있는 GitHub 계정으로 합니다.
- PDF, HWP, HWPX, DOCX, PPTX, ZIP 등 일반 파일을 올릴 수 있습니다.
- 하위 폴더 안의 파일도 자료실에서 찾을 수 있습니다.
- GitHub 브라우저 업로드는 파일 하나당 25 MiB까지 지원합니다.
- 파일을 추가하거나 삭제한 뒤 자료실의 '목록 새로고침'을 누르세요.
- README.md와 점으로 시작하는 파일·폴더는 자료실 목록에서 제외합니다.

목록을 불러오지 못하는 경우에도 공개 자료 폴더 링크로 파일을 확인할 수 있습니다.
GitHub에 저장되는 파일은 공개됩니다.
