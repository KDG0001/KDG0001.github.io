권덕규의 공부 노트 — 자료실 사용 안내

자료실 주소
https://kdg0001.github.io/downloads/

파일 내려받기
1. 자료실에서 파일 이름을 검색하거나 종류를 선택합니다.
2. 원하는 파일 옆의 '다운로드'를 누릅니다.
3. 방문자는 로그인하거나 가입할 필요가 없습니다.

파일 올리기 (작성자)
1. 자료실 위쪽의 '파일 올리기'를 누릅니다.
2. KDG0001 GitHub 계정 또는 저장소 쓰기 권한이 있는 계정으로 로그인합니다.
3. 파일을 끌어 놓거나 'choose your files'를 눌러 선택합니다.
4. 'Commit changes'로 main 브랜치에 저장합니다.
5. 자료실로 돌아와 '목록 새로고침'을 누릅니다.

파일 하나당 25 MiB까지 브라우저에서 올릴 수 있습니다.
올린 파일은 공개됩니다. 파일을 추가할 때 사이트 코드를 바꿀 필요는 없습니다.
파일 수정과 삭제는 자료실 아래 '올린 파일 관리'에서 할 수 있습니다.

추가 자료 목록이 보이지 않으면 잠시 후 새로고침하거나
자료실의 '공개 자료 폴더' 링크에서 파일을 확인하세요.
