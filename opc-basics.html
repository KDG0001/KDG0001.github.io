OPC는 왜 마스크를 다르게 그릴까

마스크에 그린 모양과 현상 후 남는 PR은 빛의 퍼짐 때문에 달라질 수 있습니다. OPC는 마스크를 미리 수정해 이 차이를 줄이는 과정입니다.

세 가지 패턴을 구분하기

Target은 얻고 싶은 형상, Mask는 빛을 통과시키거나 막는 도안, Print는 노광과 현상 모델을 거쳐 남는 PR입니다. 비교할 대상은 Target과 Print이며 보정할 대상은 Mask입니다.

교육용 모델에서 계산하는 것

마스크의 각 투과 지점에서 주변으로 퍼지는 광량을 정규화한 Gaussian 커널로 나타냅니다. 이 분포를 겹쳐 더한 뒤 threshold를 적용합니다.

I(x,y) = dose × (M * K)(x,y)
Negative PR: I ≥ threshold → PR 유지

이 식은 광량 합산 근사입니다. 위상과 간섭, 실제 장비의 파장과 NA에 맞춘 해상도, PR 화학반응과 식각까지 계산하지는 않습니다.

보정 효과를 공정하게 비교하기

격자 간격, Gaussian 폭, dose와 threshold를 고정하고 마스크만 바꿉니다. 조건까지 바꾸면 어떤 변화가 개선의 원인인지 분리하기 어렵습니다.

IoU = |Target ∩ Print| / |Target ∪ Print|
불일치 면적 = 누락 면적 + 과잉 면적

모서리 둥글어짐과 선 끝 짧아짐을 먼저 관찰한 뒤, 보정한 위치와 오차 감소를 연결해서 설명합니다.
